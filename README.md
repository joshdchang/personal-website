# personal-website

[joshdchang.com](https://github.com/joshdchang/personal-website) — built with
[TanStack Start](https://tanstack.com/start/latest) and deployed to Cloudflare Workers.

## Stack

- **TanStack Start** (on TanStack Router) — file-based routing, full-document SSR, static prerendering
- **Vite** + `@vitejs/plugin-react`
- **Tailwind CSS v4** via `@tailwindcss/vite`
- **Content Collections** — typed Markdown from `content/`
- **Cloudflare Workers** via `@cloudflare/vite-plugin` + Wrangler

## Getting started

```bash
bun install
bun run dev
```

The dev server runs at `http://localhost:5173`. It runs inside the Workers runtime
(workerd), so local behavior matches production.

## Scripts

| Script | What it does |
| --- | --- |
| `bun run dev` | Dev server with HMR |
| `bun run build` | Production build into `dist/`, then prerenders static pages |
| `bun run preview` | Serve the production build locally in workerd |
| `bun run typecheck` | `tsc --noEmit` |
| `bun run deploy` | Build and `wrangler deploy` |
| `bun run cf-typegen` | Regenerate `worker-configuration.d.ts` from `wrangler.jsonc` |

## Layout

```
src/
  router.tsx          # createRouter — router instance factory
  routeTree.gen.ts    # generated by TanStack Router, committed
  routes/
    __root.tsx        # <html> shell, head tags, error + 404 pages
    index.tsx         # the home page
  styles/app.css      # Tailwind + palette + noise overlay
  assets/             # images imported by routes
content/posts/        # Markdown, typed by content-collections.ts
```

Routes are file-based: adding `src/routes/about.tsx` creates `/about` and regenerates
`routeTree.gen.ts` automatically while `dev` or `build` runs.

## Prerendering

`vite.config.ts` enables prerendering with `crawlLinks`, so every page reachable by a
link from `/` is emitted as static HTML at build time and served straight from
Cloudflare's edge. Anything not prerendered still server-renders on demand.

## Deploying

```bash
bunx wrangler login
bun run deploy
```
